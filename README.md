# NatureFreak_hd

Static preview of naturefreak.org (direction B): a free nature photographer directory and paid features on @naturefreak_hd.

- `index.html` home, `get-featured.html`, `join.html`, `directory.html`, `profile.html`, `blog.html`
- No build step: plain HTML, deployed as-is on Vercel.
- Forms are not wired up yet. Prices and photographer names are placeholders.
- Sample photos: Pexels and Unsplash contributors.
